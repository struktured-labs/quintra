## GBDK-2020 runtime and the SDCC runtime it links

The cartridge is compiled with GBDK-2020 4.5.0 and the SDCC 4.5.1 that
ships in that toolchain (`~/gbdk/bin/lcc`). The linked runtime — GBDK's
library and the SDCC run-time library — is the third-party code inside
`quintra.gbc`. Quintra does not vendor those sources. They come from the
toolchain at build time.

- Project: GBDK-2020
- Version used: 4.5.0
- Upstream: https://github.com/gbdk-2020/gbdk-2020
- Tag: https://github.com/gbdk-2020/gbdk-2020/releases/tag/4.5.0
- Runtime license: GNU General Public License version 2, with the GBDK /
  SDCC linking exception (GPLv2+LE)
- Texts in this tree, copied from that tag's `licenses/` directory:
  - `LICENSES/GBDK-2020-4.5.0-GPLV2-LE.txt` (library license plus the
    linking exception, then the GPLv2 text)
  - `LICENSES/SDCC-runtime-notice.txt` (SDCC's own suite-license notice;
    it states that the SDCC run-time libraries are GPLv2+LE and that
    object code generated by SDCC is not itself licensed by SDCC)

The linking exception is the part that matters for a cartridge: linking
the GBDK/SDCC library into `quintra.gbc` does not, by itself, put the
rest of the cartridge under the GPL. Modifications of the library itself
stay under GPLv2+LE. Quintra does not modify those libraries.

GBDK's 4.5.0 `LICENSE` overview says a compiled ROM does not have to
ship the GBDK copyright lines, and that credit is appreciated. This file
is that credit, and it is the notice to keep with any cartridge
distribution.

These GBDK pieces are build tools or unused library options. They are
not linked into the ROM:

- lcc (LCC license), png2asset (MIT), makebin (zlib/libpng), and
  bankpack / ihxcheck / gbcompress / makecom (public domain) are host
  tools.
- The optional crash handler (zlib) is not referenced.
- zx0 decompression (BSD 3-Clause) is not referenced. Its credit
  requirement therefore does not apply to this cartridge.

## WasmBoy browser player

The itch.io / browser package vendors WasmBoy under `web/itch/vendor/`.
That bundle is GPL-3.0-or-later and is not part of the cartridge. Its
notice is `web/itch/THIRD-PARTY-NOTICES.md`, and the license text is
`web/itch/vendor/WASMBOY-LICENSE.txt`. Packaging the ROM next to WasmBoy
does not merge the two licenses. See `LICENSES/README.md`.
