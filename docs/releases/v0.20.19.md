# Quintra v0.20.19 — Clean Return

Clean Return makes every full-screen transition establish its own CGB video
memory state, including the warm Game Over restart observed on Pocket.

- Title, Game Over, champion selection, rooms, Pack, dialogue, and Victory now
  select VRAM tile bank 0 before uploading fonts, backgrounds, or sprite art.
- A leaked attribute-bank selection can no longer produce a mostly black title
  or load hero and monster graphics into the invisible tile bank.
- The Game Over regression now forces the legal leaked hardware state, verifies
  the warm title and its music, erases representative hero/enemy tiles, and
  requires the replacement run to reload them correctly.

Gameplay, balance, and saves are unchanged. Browser beta15 advances the pinned
WasmBoy fork to v0.8.13, retaining deterministic startup and rendering
coverage while centering sample decoding, using a native 44.1 kHz audio
context, and preserving exact pitch during normal play. Mobile pointer-capture
failure is also non-fatal. Quintra holds a 42 ms audio target, providing the
jitter headroom that completed the real Firefox gate without underruns.
Browser beta16 replaces the obsolete v0.20.15 launch poster with the current
title presentation and omits the volatile version row.
Browser beta17 reduces controller polling overhead and avoids per-frame DOM
writes when the selected gamepad label has not changed.
Browser beta18 prevents an idle 8BitDo DirectInput D-pad hat from stealing
selection from a controller that is receiving real input.
Browser beta19 clears touch controls on document-level release when pointer
capture is unavailable and preserves controls shared by multiple fingers.
