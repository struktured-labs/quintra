# Quintra v0.18.83 — Farfold Labyrinths

ROM SHA-256: `3c7e500c9d222e57faf025aa7973510c9afab6c2e9f65e51caef906bddf639dc`

The nine dungeons no longer reuse one fixed snake-shaped macro route. Each
stage now chooses one of eight seed-stable safe folds: horizontal districts
stay readable, while generated row crossings form real branches, dead ends,
and return paths around one learnable objective loop.

The room budget is unchanged at 20–30 rooms per stage and 219 dungeon cells
across the campaign. Every ordinary pre-service cell remains a 31×31-tile
scrolling field. The wider-feeling geography therefore comes from meaningful
route shape, not filler counters, smaller rooms, or relaxed progression.

Every approved fold is reciprocal and connected, owns exactly one loop, has
at least two dead ends and a three-way junction, and preserves a 20–31-step
Sigil/Warden/Waystone expedition. The boss cell has exactly one approach
through its sanctuary, retaining the full-heal blessing, Compass skull,
16×16 amber threshold, proximity roar, boss music, and Colossus commitment.

The screen-filling SELECT Compass draws the actual generated edges. Developer
save builders, media capture, the mGBA training pilot, and live traversal
regressions now query the same fold contract instead of assuming numeric room
order. Coverage includes all four cardinal directions, reversible horizontal
and vertical 31×31 field streaming, the full branched opening expedition,
villages, puzzles, objective gates, and all 460 five-champion Normal/Easy
checkpoint combinations.

An ordinary-input Easy Picsean run reached room 220 and defeated all nine
Colossi in 140,885 frames, below the unchanged 210,000-frame budget. A clean
emulator reproduced victory from the exact recorded buttons with 16 HP.

No room count, encounter roster, enemy HP, projectile, boss, champion,
difficulty, economy, or reward value changed in this milestone.
