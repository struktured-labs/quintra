# Quintra v0.18.77 — Long Horizons

Dungeon scale is now present on arrival. Every stage foyer and the central
back-half approach use the full 31×31-tile scrolling field, taking the opening
dungeon from eight large districts to ten and the finale from fifteen to
seventeen. The procedural graph remains 20–30 rooms; the added distance is
playable geography rather than filler counters.

Wide-field encounters now spread across four guaranteed-open sectors instead
of placing the first enemy in the east and stacking nearly every later body on
one southeast coordinate. The same generated roster therefore inhabits the
near hall, distant apron, eastern ruin, and southern approach without an extra
RNG draw or any combat-stat change.

Stage archetypes can no longer restore the old 160×136 viewport border as an
internal collision wall. Wide courts reopen that obsolete row and column after
decoration, so camera travel and body traversal describe one continuous field.

Live-ROM coverage verifies the scrolling first room, consecutive large courts,
distributed enemies, compact objective reset, and the new middle-row field.
PyBoy checkpoint generation accepts a legitimate live foyer camera and
normalizes synthetic boss-exit geometry before producing Riftwild states.
The corresponding native mGBA generator now applies the same distinction:
all 460 champion/difficulty/checkpoint fixtures cold-load through mGBA, while
separate five-minute training snapshots provide direct deeper-run entry
points. Suspend SRAM also places its test hero at the live generated field
edge rather than the obsolete compact-room threshold.

Camera follow and world-entity projection now execute in one banked pass while
the hero moves; a settled camera returns to the cheaper resident renderer. The
hardware-shaped performance gate records 179/180 ordinary frames and 144/180
dense frames, while the fixed bank retains 1,034 bytes of headroom.

An input-only Picsean run reaches the ending at frame 158,466 after all nine
bosses, with 16 HP remaining. Controller watchdog changes in this milestone
only allow the host more wall time to analyze 31×31 routes; cartridge frame
budgets, seeds, assertions, combat values, and difficulty rules are unchanged.
