# Quintra v0.20.20 — Playtest Polish

Fixes from Brandon's playtest reports (#12).

- Browser audio: the web player now recovers Safari's `interrupted` and
  `suspended` audio states on any key, tap, click, gamepad press, focus, or
  fullscreen change, and shows a "Press any button or tap to enable sound"
  banner while sound is off.
- Hunger: notices read HUNGER / NOHEAL, the HUD shows rooms left, blocked
  hearts are drawn pale, and refused shop hearts explain why.
- Difficulty: class select explains the SELECT toggle; the Pack shows EASY or
  NORMAL and labels the cycling row as TOOL.
- MP wisp at full MP shows an MPFULL notice.
- New refusal sound: a short two-note "nuh-uh" when touching something that
  can't be taken (Hunger hearts, full HP/MP, full purse, shop refusals),
  rate-limited to once per 1.5 s.

Browser build v0.20.20-beta31. The standalone cartridge is not attached to
this Release.
