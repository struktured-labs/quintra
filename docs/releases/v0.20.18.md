# Quintra v0.20.18 — Clean Slate

Clean Slate makes title rendering deterministic on hardware and browser
emulators, including reloads that retain or randomize CGB video memory.

- Title entry now clears all visible CGB background attributes before its
  animation begins.
- Stale palette, tile-bank, and horizontal/vertical flip bits can no longer
  turn the title into purple checker fragments.
- A cartridge-level regression poisons the complete visible attribute map on
  champion selection, returns through the real title transition, and requires
  every cell to be restored.

Gameplay, saves, balance, and the pinned WasmBoy fork are unchanged from
v0.20.17.
